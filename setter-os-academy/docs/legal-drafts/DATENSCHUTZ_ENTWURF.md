# Datenschutzhinweis – ENTWURF Version 2026-10 (ungeprüft)

## Prototyp (aktueller Stand)
- Es gibt keinen Server und kein Benutzerkonto. Alle Lerndaten (Anzeigename, Fortschritt, Antworten, Simulationsergebnisse, Einstellungen) werden ausschließlich im lokalen Speicher (localStorage) deines Browsers gespeichert.
- Es werden keine Cookies gesetzt, keine Analyse- oder Tracking-Dienste genutzt und keine Daten an Dritte übertragen. Schriften werden nicht von externen Servern geladen.
- Du kannst die Daten jederzeit exportieren und vollständig löschen (Einstellungen → Deine Daten).
- Gib in Übungen keine echten Personen- oder Kundendaten ein.
